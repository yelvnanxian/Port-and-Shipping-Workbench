# 普通浏览器船期采集器

这是 CMA CGM 和 Hapag-Lloyd 的人工浏览器采集扩展。它不会启动自动化 Chrome，也不会读取浏览器 Cookie 或自动处理验证码。

## 安装

1. 打开 Chrome 的 `chrome://extensions`。
2. 开启右上角“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本目录 `browser-extension`。
5. 将“港航工作台船期采集器”固定到工具栏。

## 使用

1. 在工作台的 CMA 或赫伯罗特记录详情中点击“普通浏览器采集”。
2. 复制工作台生成的一次性令牌。
3. 用日常 Chrome/Edge 打开官网，完成安全验证并完成查询；赫伯罗特固定使用完整柜号查询，并进入 Details 页面后再采集。
4. 打开扩展，粘贴令牌并点击“采集当前页面”。查询方式已经绑定在令牌中，不需要再次选择。
5. 回到工作台，等待采集状态变为成功。

令牌只绑定一条船期和一种查询方式，15 分钟后失效，成功提交后不能重复使用。页面仍处于验证码或风控页时提交会被拒绝，不会写入不真实数据。
